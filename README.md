# 照 · 四张全息闪卡

## 启动

进入 `web/`，运行 `node server.mjs`，打开 http://127.0.0.1:4173。网页已打包，无需安装 npm 依赖。页面可切换巫女、蓝伞、护士和歌姬卡片，支持拖动视角、翻面、镭射材质和 PNG 下载。

## 素材

- `web/cards/{miko,parasol,nurse,idol}/`：每张卡的单张合并立绘、背景、文字卡框、卡背及配置。
- `cards-export/`：四张卡的正面、卡背 PNG 和总览图。
- `web/assets/card.glb`：网页共用卡片几何。
- `card.blend`：巫女版的可编辑 Blender 场景。
- `renders/`：场景渲染图。

角色各自作为一个完整立绘层，卡片的背景、印刷文字和卡背按所选款式切换。角色原图来自本项目素材；网页与设计为非官方个人作品。
